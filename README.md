# Website Undangan Pernikahan

Project ini merupakan website undangan pernikahan digital yang dibuat untuk memenuhi tugas mata kuliah Pemrograman Web C. Website ini dibuat menggunakan HTML, CSS, dan JavaScript tanpa menggunakan framework.

Website menampilkan undangan pernikahan menggunakan nama random, Rizky dan Annisa, dengan konsep desain yang sederhana dan elegan. Pada halaman awal terdapat cover undangan yang berisi nama mempelai dan tombol untuk membuka undangan. Setelah undangan dibuka, pengguna dapat melihat informasi mengenai mempelai, jadwal acara, lokasi, serta informasi pendukung lainnya.

## Fitur

Beberapa fitur yang terdapat pada website ini antara lain halaman pembuka undangan, informasi mempelai dan orang tua, jadwal pemberkatan dan resepsi, countdown menuju acara, background music, serta lokasi acara yang terhubung dengan Google Maps.

Countdown dibuat menggunakan JavaScript dan akan menghitung waktu yang tersisa menuju tanggal 3 Oktober 2026 pukul 10.00 WIB. Website juga menyediakan tombol untuk mengatur musik yang digunakan sebagai background selama pengguna melihat undangan.

## Teknologi yang Digunakan

Website ini dibuat menggunakan HTML5 untuk menyusun struktur halaman, CSS3 untuk mengatur tampilan dan responsive design, serta JavaScript untuk menambahkan fitur interaktif.

Selain itu, project ini menggunakan Google Fonts untuk font Cormorant Garamond dan Poppins, Material Symbols untuk beberapa ikon, serta Google Maps untuk menampilkan lokasi acara.

## Struktur Project

```text
website-undangan-pernikahan/
│
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   ├── images.jpg
│   └── music.mp3
└── README.md
```

File `index.html` digunakan sebagai halaman utama website. Folder `css` berisi file untuk mengatur tampilan website, sedangkan folder `js` berisi kode JavaScript untuk fitur interaktif. Folder `assets` digunakan untuk menyimpan file pendukung seperti gambar dan musik.

## Tampilan dan Desain

Desain website menggunakan perpaduan warna putih, krem, dan emas untuk memberikan kesan sederhana dan elegan. Font Cormorant Garamond digunakan pada bagian judul, sedangkan Poppins digunakan untuk sebagian besar teks.

Website juga dibuat responsive sehingga tampilannya dapat menyesuaikan ketika dibuka melalui laptop, tablet, maupun smartphone.

## Menjalankan Project

Untuk menjalankan project secara lokal, repository dapat di-clone menggunakan Git:

```bash
git clone https://github.com/yelgbrl/website-undangan-pernikahan.git
```

Setelah repository berhasil di-clone, masuk ke folder project dan buka file `index.html` menggunakan browser. Project juga dapat dijalankan menggunakan ekstensi Live Server pada Visual Studio Code.
